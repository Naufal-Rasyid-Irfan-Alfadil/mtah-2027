# Pemeriksaan pilot possession eksternal 117093

Enam klip masing-masing 12 detik. Gambar lapangan tidak di-resize; ada header
48 piksel berisi nomor frame. Tidak ada proyeksi atau label provider ditampilkan.
Video MP4 terkompresi; PNG target raw tersedia untuk melihat detail diam.

Untuk setiap Q01-Q06, tonton klip lalu pause sekitar detik 6.00 pada TARGET.
Jawab keadaan tepat pada frame TARGET memakai konteks sebelum/sesudahnya:
- game_state: live / dead / uncertain. Bola tidak terlihat bukan otomatis dead.
- controlling_team_visual: biru / putih / uncertain / not_applicable. Jangan
  memaksakan tim saat perebutan tidak jelas; saat dead gunakan not_applicable.
- Jika jelas, catat nomor punggung beserta warna kostum. Ini membantu
  memeriksa mapping tim tanpa menebak Home/Away dari arah lapangan.

Format jawaban: Q01: live, biru; Q02: dead; Q03: uncertain; dan seterusnya.
Jika warna tim berbeda, tulis warna yang terlihat. Jangan membuka label raw,
report clock, atau pilot-selection-key saat mengulas. Laporkan paparan bila ada.
Semua kolom review.csv sengaja kosong sampai operator menjawab.

Ini pilot kualitas, bukan GT possession lengkap atau bukti generalisasi.
Empat klip dipilih menurut interval status provider, dua menurut waktu tetap;
prevalensi kelas dan akurasi seluruh pertandingan tidak dapat diestimasi dari
pilot. Offset raw 1040 ms berasal dari konsensus anchor event satu provider,
belum validasi visual independen. Reviewer pembuat paket telah melihat label
provider; blinding mandiri tidak diklaim. NEUTRAL tidak dipaksa menjadi D/X.

Tidak ada training/fitting/scoring model atau akses resmi. V2/R tetap kandidat.

gambar; PNG target diekstrak pada resolusi asli tanpa overlay.

diverifikasi. Bila penghentian wasit atau kontrol bola tidak dapat ditentukan
dari gambar/konteks, jawab uncertain; jangan memaksa live/dead.
